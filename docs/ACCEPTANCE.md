## 真实服务最终验收：尚未执行

当前环境缺少 OpenAI Key、Supabase 项目地址和公开 key。安全填入环境设置或 `.env.local`，执行迁移并重启后：

1. **AT-02 中文转写**：使用 HTTPS，在真实手机录制约 30 秒中文；确认 MIME、权限、暂停/继续、重录、上传、原文忠实度、编辑确认。检查含口头禅/方言的表现。不以虚拟麦克风测试替代。
2. **AT-04/05/06/08 模型**：运行 PRD A1/A2/A3，检查不把疑问当立场、不补造事实、引用跨度正确、只有一个反馈、示范需主动请求。确认账户可使用指定模型及实际费用。
3. **AT-12/15 Supabase**：在两台设备上分别注册/确认邮箱/登录；验证令牌刷新、同账户读取、第二账户禁止访问、两设备并发保存冲突处理。当前 RLS 验证运行在 PostgreSQL/PGlite，而非远程项目。
4. **PWA 真机**：iOS Safari / Android Chrome 安装、启动、后台中断、无麦克风、HTTPS 权限和离线 shell；确认拒绝后仍能文字输入。
5. **长期质量**：至少两周真实独立训练，校准同场景 rubric、任务可比性与 Memory 证据门槛。规则阈值不是心理测量结论。

这些未完成项需要真实服务配置与设备；仓库提供了完整路径，但不能据此宣称 V1 线上全部验收通过。

## 明确的实现范围

- 个人工作流使用 versioned JSONB + security-invoker 关系视图，非十张分别写入的实体子表。
- 本地账户用于开发/私人自托管；生产账户、邮件确认与云端同步使用 Supabase。
- 当前不长期保存原音，不提供音频历史对比、声学评分、TTS 或实时对话。
- 离线只提供公开 shell 与重连后的文字草稿恢复，不离线缓存私有训练历史。
- 本机测试证明当前实例可运行；未部署、未发布云环境快照、未验证全新任务恢复。
